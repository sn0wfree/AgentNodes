## 0. 一句话

十个新维度全部有硬文献锚点；其中四个（通道化 / 中性理论 / Rashomon / FormatSpread）**量化地修正了可行性研究 A1 敲除实验的预期**——「敲除无表型」不是系统失败，是被生物学预测的常态。

## 1. 十个新维度

### S1 · 通道化（canalization）→ 修正 A1 判读标准
**科学内容**：Waddington（1942 果蝇遗传同化）提出发育系统**缓冲**基因与环境扰动，野生型表型稳定；Wagner（1997）群体遗传学证明通道化演化正是因为多数突变**对野生型表型无效应**，变异以「隐秘」形式积累（[Siegal & Bergman, PNAS 2002](https://www.pnas.org/doi/10.1073/pnas.102303999)；[Stearns 2002](https://pmc.ncbi.nlm.nih.gov/articles/PMC124892)）。
**映射**：A1 敲除实验的先验预期修正——**单敲除 null 结果是被生物学预测的常态**，不是框架失败信号。可行性研究 A1 的判读标准据此修正：null → 不是「规则无用」，而是「被缓冲」→ 需要压应力才释放差异（见 S2）。

### S2 · 进化电容（evolutionary capacitance）→ 触发场景库 = 压应力实验
**科学内容**：Hsp90 作为分子伴侣缓冲突变效应；压应力或药物破坏缓冲后，**隐秘变异被释放**，大量新表型涌现——「形态演化的电容」（[Rutherford & Lindquist, Nature 1998](https://www.nature.com/articles/nature02322)；[Queitsch 2002，引用 ~1755](https://www.nature.com/articles/nature02322)；2025 年 eye evolution 再证 [Nat Commun](https://www.nature.com/articles/s41467-025-65027-0)）。
**映射**：**触发场景库 = 电容破压实验**——规则在常规路径被缓冲，在应力场景（边缘输入/对抗/资源紧张）才显效。⇒ 触发场景库必须**含压应力型场景**，不能只测常规路径——这是对 M3 场景设计的一条硬要求。

### S3 · 不完全外显 & 表现度 → 「遵守率」的正统学名
**科学内容**：基因型在场而表型不显 = **不完全外显**（penetrance <100%，BRCA1/2 等经典例）；表达程度差异 = 表现度变异；受修饰基因与环境/表观影响（[Kingdom 2022, 引用 264](https://pmc.ncbi.nlm.nih.gov/articles/PMC9380816)；[Nature Scitable](http://www.nature.com/scitable/topicpage/phenotype-variability-penetrance-and-expressivity-573)）。
**映射**：「transcribed ≠ enforced」获得正统学术名词——规则的外显率 = 群体级遵守率百分比；个体级 = 二值判定。⇒ 表达谱报表把「遵守率」标注为**外显率**；uncertain 的来源（上下文修饰）与 bio 的修饰基因同构——概念对映表补一行。

### S4 · 中性理论（Kimura 1968）→ 预期管理与 ratchet 的成因
**科学内容**：分子水平**约 95% 新突变是选择中性的**，命运由随机漂变决定；选择只作用于少数大效应突变（[Wikipedia 综述](https://en.wikipedia.org/wiki/Neutral_theory_of_molecular_evolution)；[Kimura 1989](https://pubmed.ncbi.nlm.nih.gov/2687096)；[Nature Education](https://www.nature.com/scitable/knowledge/library/neutral-theory-the-null-hypothesis-of-molecular-839/)）。
**映射**：**预期管理**——50 条规则里能被 eval 选择出来的（显著 Δeffect）预计只是少数；其余是中性积累。⇒ A1/M3 的预期修正（同 S1）；**中性积累同时解释了规则库为什么越堆越多**——没有选择压力清除中性规则 → 联动 S6。

### S5 · GWAS 方法论 → C11 的统计机制来源
**科学内容**：群体级性状归因（位点↔性状）需要 **P<5×10⁻⁸** 全基因组阈值（≈100 万独立检验的校正）；小效应位点需数万样本；欠功效研究呈「平 Manhattan 图」——有 suggestive（1e-5–1e-6）无显著位点。
**映射**：我们的规则归因 = **一场迷你 GWAS**：50 规则 × 行为的多重检验负担同构 → C11 的 BH-FDR 校正直接继承 GWAS 机制；报告分级沿用其惯例（**significant / suggestive / null** 三档，不许把 suggestive 写成显著）。预注册阈值 = 我们自己的 5e-8。

### S6 · Muller's ratchet / error catastrophe → U4d 退役的理论必然性
**科学内容**：无性种群**不可逆**积累有害突变（ratchet 只进不退），最终信息崩溃；只有补偿突变/稀有有利突变可停摆（[Matuszewski 2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC6007402)）。
**映射**：规则库只增不减（无退役）= ratchet；「规则堆积 → 拥挤降性能」（可行性 D4）= **error catastrophe 的工程版**。⇒ U4d 退役机制 + A5 规则密度预算从「好习惯」升格为**理论必然性**——ratchet 不可逆，退役必须制度化。

### S7 · 影子增强子 & 冗余 → 双敲除的方法论先例
**科学内容**：发育调控网络中**冗余增强子**普遍存在，突变主增强子时影子增强子补偿，表型被缓冲（[Cannavò 2016, Curr Biol](https://www.cell.com/current-biology/fulltext/S0960-9822(15)01428-1)；[Osterwalder 2018 Nature, ~800 引](https://pmc.ncbi.nlm.nih.gov/articles/PMC8068586)；[Kvon 2021 综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC8068586)）。治疗侧：**合成致死**的 PARP/BRCA 范式——BRCA 缺陷细胞靠平行通路存活，抑制 backup（PARP）选择性致死（[PMC5528309](https://pmc.ncbi.nlm.nih.gov/articles/PMC5528309)；[STTT 2024](https://www.nature.com/articles/s41392-024-01893-2)）。
**映射**：单敲无表型的机制之一 = 冗余备份（规则 B 隐性覆盖 A）→ D13 合成致死有了**临床级先例**：双敲除设计（M3 扩展项）不是发明，是把 PARP 范式搬进规则域——先敲常用规则，再敲影子规则，找「影子对」。

### S8 · 克隆选择（Burnet，教科书级）→ 提案闸的免疫学先例
**科学内容**：适应性免疫 = 多样性生成（V(D)J 重组）+ **阳性/阴性双向选择**；克隆删除清除自反应细胞，形成自体耐受。
**映射**：GenomeProposal 多样性生成 → validation_gate 双向筛选 = 克隆选择的工程版；gate 拒绝奖励黑客提案 ≈ 阴性选择；instruction hierarchy 的 self/non-self 识别再获一条佐证。【教科书级，未逐字核】

### S9 · Rashomon 效应 / 模型多重性 → D1 的 CS 侧独立证据
**科学内容**：Breiman（2001）指出同一数据存在**多个同等准确的模型**，给出不同解释；模型多重性使归因/解释取决于「挑了哪个模型」，构成根本性歧义（[Black 2022, ~262 引](https://arxiv.org/abs/2202.12754)；[ACM CSUR 2025 综述](https://dl.acm.org/doi/10.1145/3699682)；Rudin 2024 论其正面用法 [arXiv 2407.04846](https://arxiv.org/html/2407.04846v1)）。
**映射**：**D1 归因天花板不只生物有，AI 自己就有**——同一行为可由不同权重路径产生，规则归因天然歧义。⇒ 归因报告必须带**不确定性声明**；Rudin 的正面用法值得偷师：**在等效规则组合（Rashomon 集）里挑最小集 = 最小基因组实验的另一种实现**。

### S10 · FormatSpread 格式敏感性 → 敲除实验的格式控制纪律
**科学内容**：**保义**的 prompt 格式变化（空格/分隔符/大小写/标签风格）造成最高 **76 分**的性能摆动（[Sclar 2023 / ICLR 2024, ~1600 引](https://arxiv.org/abs/2310.11324)）。
**映射**：prompt 实验的**噪声地板**——比 run-to-run 30% 方差（可行性 D3）更猛的混杂源。⇒ 敲除对照必须**逐字节同格式**（唯一 diff = 被敲规则本身）；genome_snapshot 的装配链字段需显式记录格式（分隔符/顺序），并作为受控变量校验——格式变化 = 无效实验。
