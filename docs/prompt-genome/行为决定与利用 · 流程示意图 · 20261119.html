流程口诀

定义行为：基因库 → 按 task_signature 转录 → 装配 prompt → 模型翻译成行为。
看见行为：trace 同迭代绑定 + eval 指纹 ⊕ 基因组版本。
改变行为：归因找到承重基因 → 变异（提案）→ 选择（闸）→ 遗传（新版本）；快路径走拉马克沉淀（带来源 trace）。
借外部：业界保守位点观察 → 证据包 → 只能从提案闸进来。
评估锚点（看图自问三问）： ① 定义链的选择性——② 若不做「按 task_signature 选规则子集」（★B6），①→③ 就是全文注入：基因组 = 转录本，⑦ 归因的「表达谱」将无信息量。这条决定整张图左半边的价值。 ② 三卡的证据强度不同——卡1/卡2 是因果（Rung 2，可写 Δeffect），卡3 是关联（Rung 1，止于「表达层面相关」）；任何对外报告是否把三者的结论强度分开标注？ ③ 两条回路的配比——琥珀拉马克快但污染风险高（来源 trace 是唯一防线），绿达尔文慢但可信（过闸才遗传）；skill 沉淀量与闸通过率的比例是否有人盯（对接 F21 审查节奏）？
