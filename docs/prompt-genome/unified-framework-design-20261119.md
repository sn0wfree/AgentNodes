# 提示词基因组 · 统一框架设计（UPGF）

> **目标**：把五份材料（业界框架草案 / 语料评估 / 概念对映 / 规则基因组 v2 / GRL）合成**一个**框架——不是拼盘，是互相补齐的闭环。
> **状态**：部分拍板——**U4 已拍板**（2026-11-19，见 §3.1）；U1 / U2 / U3 / U5 待拍板。未实施。上位文档：[`rule-genome-synthesis-20261118.md`](rule-genome-synthesis-20261118.md)；未决清单沿用 [`rule-genome-design-20261117.md`](rule-genome-design-20261117.md) §10。
> **口诀**：**一语 · 一表 · 一脊，两域 · 一回路。**

---

## 0. 一句话

**一个基因组系统（G→E→P→进化），两个研究域（自仓可干预 S / 外源只观察 W），一门语言（GRL），一条进化回路（W 观察 → S 进化）。**

## 1. 为什么统一：五份材料各自停在半途

| 材料 | 已贡献 | 停在哪（缺口） | 统一框架中的位置 |
|---|---|---|---|
| 业界先例调研（框架草案 L1/L2/L3） | W 域方法论：发现/编码/对齐管线 + 24 可抄件 + 13 必自研件 | 无可执行语言；无自仓闭环——结论只能停在报告 | **W 域管线**（§4 左侧） |
| CL4R1T4S 评估 | 语料纪律：provenance 分级 / 注入防御 / AGPL 瑕疵 | 只是评估，不是系统组件 | W 域**语料守则**（§6 约束 C7） |
| 概念对映研究 | 生物学设计规则（9 承重概念 + 5 失效边界） | 不是工程，无落点 | **全框架约束层**（§6，C1–C9） |
| 规则基因组 v2 | S 域全设计：Registry / trace 绑定 / 归因三法 / M1–M3 | R-xxx 是自编号——**无语义位点坐标系**；无外源输入 | **S 域管线**（§4 右侧） |
| GRL 基因规约语 | 等位层可执行语言：5526 条款闭环自证 + tier/modality/eval 字段 | 无观测绑定（trace）；无归因；locus 语义依赖先验 D01–D23 | **一语**（§3.1） |

**统一后的互补关系**：GRL 给位点表提供等位层实现 ↔ 位点表给 GRL 提供 locus 语义；trace 给 GRL 对象提供表型挂钩 ↔ GRL 的 eval 字段给 trace 提供分数关联键；W 域给 S 域提供进化材料 ↔ S 域给 W 域提供位点权重的行为验证。**每条边都是双向有用，这才叫统一。**

## 3. 五个统一决策（本框架新增，需拍板）

| # | 决策 | 内容 | 依据 |
|---|---|---|---|
| **U1** | **两域不对称原则** | S 域是模式生物（可敲除、可变异、可写 Δeffect 因果结论）；W 域是野生种群（只可观察，结论止于「表达层面相关」）。**两域归因语义不同且不可混用** | 概念对映 §4.3 推论一（转录本≠基因组）；敲除在 W 域不可行（厂商 prompt 固定） |
| **U2** | **GRL id 即全局 rule_id** | S 域沿用 `R-001…`；W 域用 GRL 现行方案 `R-<VENDOR>-<SCOPE>-<NNNN>`。两域 id 同空间不重叠，一条 ID 脊柱贯通 | GRL §2.1 已有稳定 id 方案；规则基因组 v2 §3.5 URI 规范直接扩展 |
| **U3** | **证据 URI 增补 `ext:` scheme** | `ext:<vendor>/<file>/<clause_id>` 指向 W 域条款；未知 scheme 依旧拒绝（fail loud） | 规则基因组 v2 §3.5 三 scheme 的自然扩展 |
| **U4** | **位点表治理** | ✅ **已拍板（2026-11-19，全部采纳）**——完整裁决、业界先例映射与两处度量修正见 **§3.1** | Hennig 2007 / GO / Protobuf / Confluent / SC3 / ICD-11 |
| **U5** | **进化回路单向** | W→S 只能经 GenomeProposal 闸（外源观察结论打包成提案证据）；**S→W 无写路径**（我们不改厂商 prompt，只给 W 语料加注释层）；Tier 0 位点（安全底线类）编译器硬拒覆盖 | GRL 已实现 Tier 0 编译器硬拒；规则基因组 v2 三铁律之「观测者≠被检方」 |

### 3.1 U4 拍板记录（2026-11-19 · 全部采纳 · 含两处修正）

**裁决一 · 表的形态（U4a）**：locus ID 一经发布**永不删除**；变更定义 = 新增 ID + 旧 ID 标 `deprecated` + `replaced_by`（自动迁移）/ `consider`（人工审）双轨别名；表为版本化工件 `locus_table.json`，`table_sha256` 记录在**编码批清单级**（不逐对象携带）。deprecated ID **禁止重定义**——解析器 / CI 机检拒绝（等价 protobuf `reserved` 墓碑）。表演化政策声明为 **BACKWARD**（新表必须能解释旧 GRL 对象）；将来若需大版本（位点重编号），必须配套迁移表工件（ICD-11 教训：坐标系大改是十年级成本）。
先例：GO「terms are never deleted」（Gaudet 2017）+ OBO `replaced_by`/`consider`；protobuf never-reuse-field-numbers；Confluent Schema Registry BACKWARD/FULL(_TRANSITIVE)。

**裁决二 · 来源权威（U4b）**：W2 聚类**盲跑**（不给先验标签）；先验 D01–D23 靠与盲发现簇**匹配**挣 `confirmed`，匹配不上降 candidate——同时完成业界调研 §8.1 要的外部验证机会。位点表加 **`applies_to: [S|W]`** 字段（≈ GO slims 按社区裁剪子集思路【存在性已核，细节引用前再核】）；**L1 回路（保守/空白位点对照）只在 S∩W 共有位点上跑**。外部人工维度集（SysPrompt-Forge 7 轴、PromptPrism 三层等）为挑战集，不直接入表。

**裁决三 · 稳定性闸协议（U4c，修正设计稿度量）**：
- **修正 1（度量）**：原「位点集 Jaccard」不成立——标签文字跨 run 必然不同，裸标签集 Jaccard 恒近 0。改为两级：**全局分区一致性 = ARI**（整轮失败线）；**逐位点稳定性 = 成员 Jaccard**（Hennig 2007 簇级方案，R `fpc::clusterboot` 标准）。
- **修正 2（阈值）**：分带不发明，采用 **Hennig/fpc 公开约定**——成员 Jaccard 均值 **≥0.85 很稳 / ≥0.75 confirmed / 0.5–0.75 candidate / <0.5 unstable**。全局 ARI 无 canonical 阈值 → **预注册自设：mean pairwise ARI ≥0.55**，否则整轮判「发现失败」；W2 现场不得改判据，修订须记录后再改。
- 分级制：confirmed 入表进脊；candidate 只进报告（对齐 C9 一等状态）；不把整轮发现一刀切扔掉。
- 参数（自设预注册）：**N=5（下限 3）**；温度固定 + 模型版本进 provenance；成本控制——闸先跑分层抽样（~1500 条），处于分带边界再全量复跑。
- 位点数选择：共识聚类 **PAC**（Monti 2003，取歧义占比最低的 k），与上轮 APE 维度-收益曲线（14–16 达峰）交叉对照。

**裁决四 · 增删流程（U4d）**：新增 = 提案制——证据 = 落不进现有位点的条款 **≥10 条**（自设预注册值）→ 人工评审（git diff 即表 diff）→ append → 版本 bump。退役 = 连续观察窗两域零指派 → `deprecated` + 注记迁移建议（GO 判据：out of scope / 误导命名 / 概念另有更佳表示）→ 对接 3 个月审查周期（F21）。历史完整，永不物理删除。

**裁决五 · 条目 schema（落地件）**：locus_table.json 每条目
`{locus_id, short_name, definition, text_sha256, applies_to:[S|W], status: confirmed|candidate|deprecated, replaced_by?, consider?, stability:{mean_jaccard, runs, ari_global}, source: blind-discovery|prior-match|external-challenge|self-proposal, added_in_table_version}`。

**落地影响**：W2 相位按裁决三执行（§5 已同步）；M1 registry 解析器新增机检「deprecated locus 重定义报错」；业界调研 §5.2 #1 与 §6.3 已加修正标注。

**诚实边界**：GO slims 细节未逐字核；Hennig 分带出自 fpc 文档约定而非硬标准；N=5 / ARI 0.55 / 证据 10 条为**自设预注册值**（业界无先例），不适用时走预注册修订流程。

## 4. 统一流水线（吸收业界框架草案 L1/L2/L3 + 规则基因组 M1–M3）

业界框架草案的三层在这里**按域重排**——它原本是 W 域专用管线，统一后 L1/L2 上提为两域共享，L3 按域分裂为「对齐（W）」与「归因（S）」：

| 阶段 | 原 L 编号 | 去向 |
|---|---|---|
| 条款原子化 | L1① | 两域共享（SPDeconstruction 提示词为基线；S 域即 rules.md 解析） |
| 位点候选归纳 | L1② | **一表 · W 源**（两段式聚类 + 稳定性闸） |
| 位点 schema 定稿 | L2④ | **一表 · 治理**（U4：版本化工件） |
| 取值器 | L2⑤ | **一语 · GRL 编码器**（双通道：MICoL 软 + IFEval 硬——业界调研 §3.12） |
| 序列化 + 双口径报告 | L2⑥⑦ | GRL 对象即序列；双口径（覆盖广度 × 约束强度）进 W 域报告 |
| 逐位点对齐 / 共识序 / 家族聚类 | L3⑧⑨⑩ | **W 域管线**（家族用网非树 + null 树负对照——C4 约束） |
| 变异 / 晋级 / 回滚 | L3⑪ | **S 域管线**（GenomeProposal + validation_gate，已有） |
| （无对应） | — | **S 域归因三法**（表达谱/敲除/关联键，规则基因组 v2 新增的部分） |

## 6. 约束层：生物学的九条架构约束（C1–C9）

概念对映研究的 9 个「承重」判定，在此固化为框架的硬约束（违反任何一条 = 框架退化为修辞）：

| # | 约束 | 来源概念 |
|---|---|---|
| C1 | W 域结论止于「表达层面相关」，禁写因果 | 转录本≠基因组（R5） |
| C2 | S 域归因以敲除为 gold standard，无对照不上报告 | 基因敲除 / 本底 |
| C3 | 「最小可活 system prompt」消融 = S 域行为验证的终实验形态 | 最小基因组（473 基因，1/4 功能未知照删） |
| C4 | W 域家族聚类给**网**不给树；树必须配打乱位点 null 树负对照 | HGT / 网状进化 |
| C5 | 基因组写回只走双通道：闸门通道（提案→gate）与拉马克通道（沉淀→来源 trace），分开计量 | Weismann 屏障 / 拉马克 |
| C6 | provenance 是替代缺失校对酶的唯一手段：两域对象四元组齐全（源文件/版本/抽取时间/抽取模型） | 复制保真度 |
| C7 | W 域语料单文件按需取、声明不可信输入、绝不整仓进管道；AGPL 瑕疵语料不进训练/分发 | CL4R1T4S 评估 F1/F4 |
| C8 | 位点 schema 是协商与版本化的对象（无普适解码表）；改 schema 必须改版本号 | 中心法则边界 |
| C9 | 「未识别 / uncertain / null」三处均为一等状态，任何通道禁止兜底成默认值 | JCVI-syn3.0 的 1/4 功能未知基因 |

五条**失效边界**（概念对映 §3）继续作为「不许暗含的假设」全框架生效，不重复罗列。

## 8. 不做清单（继承 + 新增）

继承规则基因组 v2 全部不做清单（无逆向归因 / 无跨规则排名 / 无独立观测存储），新增：
- **不做 W 域优化**：对厂商 prompt 做变异/评分是 R2 混淆源（EoT 的事），W 域只有编码与对齐；
- **不做两域 schema 强行同构**：S 规则有 verifier/严重度字段、W 条款有 negation/condition 字段——自然不对称，共享的是 locus 坐标系与 GRL 骨架，不是全字段；
- **不做「业界最佳实践直接抄」通道**：W→S 回路只提**证据**（谁有什么、我们没有），判断与改写永远发生在 S 域提案流程内（防 CL4R1T4S 式照搬 + AGPL 风险，C7）。

## 9. 证据边界

- 本文是**设计综合**，不含新事实；所有数字与机制可回溯至专题五份文档（见 INDEX.md §0 地图）；
- GRL 的「5526 条款闭环 / 18 机检判据」**转述并行会话自述，未独立复现**——W1 相位执行时将天然完成复验（批量编码跑通即为复现）；
- 位点表 W 源的两段式聚类稳定性引用 MDPI 作者自报（重复跑差 15%），U4 闸值需在 W2 现场定，不预设；
- 本框架未在本地跑通任何相位，全部验收判据待实施时兑现。
