00 一句话

物理轴（L1–L4）管「谁可以 import 谁」，语义轴（G/E/P）管「谁可以改变谁」；
两轴在 Tier 0/1/2 相交；三条反馈回路按分钟 / 小时 / 天分时标运行；
评估器与变异白名单的守护在进程外。

02 六条理念 · 每条 = 实测张力 + 规则 + 可执行检查
理念 01
双轴正交：物理轴管依赖，语义轴管变异
张力GEP-RSI 的全部缺口在 import 图上恒为 0——物理门禁全绿 ≠ 架构对
规则两轴不互相推导也不合并；桥接点是 Tier 0/1/2
检查物理轴：AST 门禁（已有）；语义轴：W4 待建
理念 02
变更三关口：提案 → 验证 → 留痕
张力能直接改配置的 agent 总能把指标调好看
规则GenomeProposal 唯一入口（构造期拒 Tier 0）→ ValidationGate 唯一生效入口 → 事件 + 版本链 append-only
检查三道已成立；缺口：set_tier2 全仓零调用（Tier 2 设计了没接线）
理念 03
注册即可运行，或不可见
张力26 个业务工具注册成功、调用必败（CapabilityNotFound）——端口化把失败从编译期推到运行期
规则kind 注册的前提 = 全部依赖 kind 可解析；不满足 → 整组不注册 + WARN 事件，绝不注册必然失败的壳
检查W1：工厂声明 requires 依赖清单，装配期拓扑自检
理念 04
评估器在循环外，终止层级在进程外
张力评估器可被循环改写 = 自进化退化为自欺骗；「永远不可变」又不可实现
规则评估器不在 Tier 1 白名单（闭合集合）；修改唯一路径 = PR + 人审 + 包外门禁；终止层级 = scripts/arch + 测试 + 人
检查1–3 已成立；W4 补评估完整性指纹（评测前校验，不符即 escalate）
理念 05
两条反馈回路不合并，goal 是桥
张力合并会把两种噪声混在一起，并让「把判据写松」成为指标攻击面
规则能力反馈（golden eval，冻结基准）喂第 5 步双门；任务反馈（goal journal，判据证据）喂第 1 步诊断；端口方向恒为 L2 实现 → L3 消费
检查JournalSource / ScoreboardSource 协议已声明；rsi_wiring 四源同指是待修 bug
理念 06
没有驱动的循环不存在
张力五个零件各有测试，build_rsi_loop() 生产零调用——七步之外缺第 0 步：谁拉起一轮
规则主驱动 run.settled 收尾钩子 + cron 兜底 + 每 session 至多 1 cycle（复用容量闸）
检查W4：rsi.cycle_started / cycle_skipped(reason) —— 没有驱动也必须以事件现形
