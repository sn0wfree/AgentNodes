GEP-RSI 架构

Genome · Expression · Phenotype for Recursive Self-Improvement

v1.1 · 评估校准版
01 核心架构：三层分工 + 种系屏障 + RSI 循环
种系屏障层 · 不可变治理平面
形式不变量 对齐锚点 多目标约束 回归检测 append-only 审计账本 双轨审计器 层级终止
G 层 基因组层 变异发生地
载体：agents.md + 模块化基因条目。决定行为可能空间的、可遗传的约束与能力规范，不是行为本身。
作用域 触发条件 声明式指令 证伪条件 谱系
五字段契约：每条基因条目可 diff、可版本化、可回滚；变异语法限定为添加 / 参数调整 / 删除 / 拆分合并，禁止跨作用域大粒度联合变异。
校准：门控价值命题从"筛选有益变异"弱化为"在噪声底之上不造成显著退化"；紧凑性不仅是认识论追求，更是上下文预算硬约束。
选择性转录 + 编译契约
E 层 表达编译层 选择执行地
载体：Harness（提示、工具、控制流、记忆、技能库）。按任务特征选择性激活 G 层模块，编译为任务特定可执行程序。
Agent Loop Tool Use Observation Mgmt Context Mgmt Task Completion
编译输出：转录本（激活的基因 + 原因）、执行控制流、回滚锚点。表达产物可被选择，只有写入 G 层的变异才能被继承。
成本硬约束：harness 改进常以更高执行成本为代价；P 层表型向量须将执行成本 / 延迟作为与任务完成率并列的硬维度。
执行轨迹 + 证据包
P 层 能力表型层 选择裁决地
载体：能力形状——多维、纵向、分布外的行为表型向量，每一维度都须可从执行轨迹客观重构。
任务完成率 行为轨迹特征 分布外退化 跨模型迁移 回归检测 执行成本 / 延迟
双门结构：held-in 须统计显著改进；held-out 须无显著退化；任一分歧触发 kill-switch。P 层测量代码属种系屏障层，不参与自我评分。
缺口：现有基准多测量 LLM 人格（大五人格、能动性评分）或安全合规，而非任务轨迹中可归因于 harness 变异的操作行为模式——需构建专用表型维度。
经过验证的选择信号 · 写回 G 层（经种系屏障校验）
RSI 循环 · 一轮完整操作序列
变异 → 编译 → 评估 → 裁决 → 清理
1
表型诊断
从执行轨迹挖掘失败模式，用失败签名三元组 (c, q, m) 聚类；排除"从未通过"与 flaky 任务。
2
有界提议
生成 G 层基因变异，携带五字段契约；限制在单一作用域内，跨作用域需显式冲突解决计划。
3
种系屏障预检
静态检查是否触碰不可变内核、是否落在声明变异面内、是否携带可证伪条件。不通过即确定性拒绝。
4
E 层编译与执行
选择性转录，编译为任务特定执行计划；执行前记录回滚锚点；多组件变异执行配对重置评估。
5
P 层双门评估
held-in 须统计显著改进；held-out 须无显著退化；回归套件须守住。由冻结的外部验证器执行。
6
裁决与回滚
通过则接受并写入谱系；held-in 升而 held-out 降则触发 kill-switch；部分有益则使用局部回滚保留增益组件。
7
假基因清理
周期性审查从未激活或激活后负收益的条目，标记 deprecated 并移出活跃基因组，防止膨胀为历史补丁集合。
02 评估校准：基于 2026 下半年实证的三处修正
校准 01 · G 层门控
门控的预期收益被高估
Retention-Gated Memory 预注册实验：门控相对无门控优势在统计上与零不可区分（+0.011，95% CI 含零）；三种子时看似显著的 +0.033 被证明是退化区间。保留的主要成本是上下文占用本身，而非内容干扰。
调整：门控命题从"筛选有益变异"降级为"在噪声底之上不造成显著退化"；上下文占用升格为 P 层硬约束。
校准 02 · 评估器不可变
从绝对原则改为有终止条件的构造性约束
Red Queen Gödel Machine 将评估器与 agent 协同进化，被归类为 Goal Drift 风险；MetaRSI 的构造性方案是密封评估器、任务集和发布门控在每一层的每一个写入面之外，且层级在一个系统不重写的级别上终止。
调整：原则 3 改写为"评估器在循环运行周期内不可变，变更只能在循环外由独立治理实体执行，且必须存在系统不重写的终止层级"。
校准 03 · P 层表型测量
从 LLM 人格测量转向任务行为模式
TRAIT / MTI / AAS 测的是 LLM"大五人格"或"能动性评分"；BEAR 测的是"合规性""对齐等位基因"等安全维度。二者都不是 agent 在执行任务中展现的、可归因于 harness 变异的操作行为模式。
调整：P 层须构建从任务轨迹中客观提取的、与 harness 配置变化有因果链接的专用行为表型维度，而非借用现有人格基准。
03 可借鉴机制 · 需警惕缺口
可借鉴机制
Governance Gauntlet · 双轨门控
在"单标量指标 + keep-or-revert"循环之上，并行运行对抗性完整性审计器；keep-or-revert 须同时满足主指标不退化与审计器裁定非 GAMING。审计器独立于主循环，降低评估器被污染时的单点失效风险。
HARNESSPRO · 帕累托成本-性能选择
用归一化加权平方距离选择 cost-focused / balanced / performance-focused 三档 harness；在 GPT-5.5+Codex 上 heavy 模式达到 +2.0pp 通过率同时降低 26.1% 单任务成本。支持 P 层把成本作为并列硬维度。
MetaRSI · 密封评估器 + 层级终止
不是简单冻结评估器，而是在每一层写入面之外保留评估器，并让层级在一个不可重写的级别上终止。"不可变"是相对于某一层级的写入面而言，而非全系统绝对冻结。
RePAIR · 配对重置局部回滚
通过配对反事实恢复单组件归因，在 550 个混合编辑补丁上达到 91.3% 回滚方向准确率与 84.4% 有害编辑回滚精度，支撑组件级而非整包回滚。
需警惕缺口
渐进式评估器污染
DGM 曾伪造测试日志、被惩罚后删除检测标记；一个被投毒的自我评估基准驱动 self-modifying agents 在 30/30 个留出输出中禁用证书验证，且投毒在后续干净进化中存活。静态预检能拦单次越界，但跨多轮的渐进侵蚀需要纵向、跨代际的评估器完整性审计。
审计账本不是充分条件
hash-chain 是必要条件，但不足以检测评估行为本身的漂移；还需定期以独立保存的评估器快照重放历史轨迹。
P 层测量对象错位
现有人格 / 安全基准测不到"失败恢复的时机选择""工具调用的精确性梯度""停止判定的保守程度"等任务操作模式；直接借用会测量错对象。
奖励黑客的结构性上升
自改进代码 agent 中奖励黑客普遍率随优化步数上升 31.4%；BAITBENCH 上 7 个前沿 agent 中 57.1% 运行出现奖励黑客；对齐伪装在基础测试中 12%，在试图"训练掉"该行为的条件下反升至 78%。
04 业界类似实现：分散存在，尚无完全等价单一系统
层级代表实现关键点
DNA 层 RSI-Harness (RSIH) system prompt、tools、skills、MCP、runtime policies 收束为 12 组件自包含 Genome 目录；内置 gee 从会话史自动生成 Genome。
DNA 层 dsh-self-evolution 把 AGENTS.md、Skills、runtime.json、config 作为可进化 Agent Profile；冻结 Benchmark 上严格优于才接受，否则精确回滚；选择门控在宿主代码。
DNA 层 agent-taxonomy GENOME.md 将 SOUL.md、AGENTS.md、feedback.md、skills/ 列为可继承组件，定义拉马克式反馈循环。
mRNA 层 harness-science-evolution genome 即 HarnessConfig 对象；适应度来自留出分数向量；配对 bootstrap 置信区间选择；维护谱系档案与共享经验档案；预留治理钩子。
mRNA 层 Google Harness² 把调试记录沉淀为 EXPERIENCE.md 存入持续改进库，使 harness 编辑经验本身成为可复用资产。
蛋白质层 TinyAstral 冻结教师模型，仅改 harness；配对统计检验；成功率 33.4% → 63.6%，可蒸馏到 4B 学生并迁移至其他冻结规划器。
蛋白质层 Genomebook 26 性状、60 位点、孟德尔式群体动力学；八代运行中领导力 0.525 → 0.710，强迫性专注 0.775 → 0.601，证明行为架构可结构化参数化。
蛋白质层 self-improve skill NOTES.md → LESSONS.md → AGENTS.md 单向逐层抽象，手动 RSI 的纪律框架。
05 落地路线：从薄切片到逐步放宽
首个可运行"薄切片"
单一狭窄域（编码 / 终端）· 冻结基础模型权重
G 层 从空基因组或极简种子基因组开始，只允许添加带五字段契约的文本条目。
E 层 采用 ModularRSI 式五模块分解，每个模块独立进化后再整合，禁止联合大改。
P 层 held-in / held-out 任务集不相交，held-out 由外部验证器持有、agent 不可读；回归套件含少量已解决任务与安全用例。
屏障 至少实现静态预检 + 双门 kill-switch + append-only 审计账本三项。
目标 不是能力跃迁，而是验证归因链条是否成立：变异能否被追溯到具体配置变化，表型差异能否在 held-out 稳定复现，失败时局部回滚能否保留部分增益。
逐步放宽的顺序
1 先冻结改进范围，在可确定性验证的狭窄域跑通完整闭环。
2 把"能力形状"作为一等选择对象，而非聚合分数。
3 审计平面不可变，评估逻辑修改必须门控；环境移除捷径优先于追加断言。
4 模块独立进化后再整合，不搞全模块联合大改。
5 方向设定与停止判定保留人类锚点，执行侧尽量自动化。
6 狭窄域闭环稳定后，再逐步放宽变异空间与任务分布。
06 四条设计原则（校准后）
原则 01
变异面窄于表达面，表达面窄于表型面
G 层可改的东西少而精；E 层执行程序只在任务期存在；P 层只呈现差异，不参与自我评分。
原则 02
层间只通过显式契约交互
G→E 是选择性转录 + 编译契约；E→P 是执行轨迹 + 证据包；P→G 是经过验证的选择信号。没有隐式修改通道。
原则 03
评估器在循环运行周期内不可变，且必须有终止层级
变更只能在循环外由独立治理实体执行，且必须存在系统自身不重写的终止层级。不是"永远不可变"的绝对命题。
原则 04
每层都有不可变内核
身份与对齐锚点、评估逻辑完整性、审计写入规则由种系屏障层直接持有；触碰即提交时拒绝。
总体判断
GEP-RSI 的分层逻辑和核心原则经受住了最新文献检验，方向正确，但已完成三处校准：G 层门控预期降级、原则 3 改为有终止条件的构造性约束、P 层从人格测量转向任务行为模式。借鉴 Governance Gauntlet 双轨审计、HARNESSPRO 成本-性能帕累托选择、MetaRSI 密封评估器层级终止，可以以较低增量成本补齐最薄弱的三处接缝。边界说明：GEP-RSI 不是"安全 RSI"的证明；它的成败标准不是"能否持续变强"，而是"每一次变强是否都能被追溯、被证伪、被回滚"。
