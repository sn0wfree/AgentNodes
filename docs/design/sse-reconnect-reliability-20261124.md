# SSE 重连与恢复修复

> 2026-11-24 · 修复说明和待验收记录

## 当前状态

代码和回归测试已修改，尚未提交。定向测试通过，但完整异步测试和重启后端后的
浏览器端到端验收尚未完成；因此不能据此认定线上问题已经消失。

原始日志显示，多次重连的游标为空，并伴随历史事件重复回放；此前对真实浏览器
连接注入不落库的业务错误时，复现了连接仍为 OPEN 却被标记断开，随后被看门狗
重建。这个实验支持业务错误触发误重连的结论，但不能证明日志中的**每一次**
断线都由该路径造成。

## 问题与范围

- 浏览器实测业务 `error` 事件会同时触发 `EventSource.onerror`，健康连接被误标为断开，
  随后看门狗关闭并重建连接。新连接没有游标，后端重新发送历史事件。
- 聊天 SSE 游标不存在时，现有过滤持续跳过实时事件；回放结束后才注册实时队列，
  期间产生的事件可能丢失。
- 工作流 SSE 连接未携带认证令牌；历史视图连接错误时关闭，不能原生重连。
  运行流没有事件 ID，重连会重新发送事件。
- 既有前端替身未模拟业务 `error` 同时触发 `onerror`。

## 契约和步骤

1. 区分业务 `MessageEvent` 与连接错误；保持错误提示和原有真实断线恢复。
   同一会话手动重建时携带已处理事件的最后 ID，切换会话时清空；不持久化跨刷新游标，
   避免刷新后状态未恢复却跳过历史事件。浏览器原生重连优先使用请求头。
2. 游标不存在时记录警告并回退完整回放，不允许无限跳过实时事件；
   先注册实时队列再回放，对重叠事件按 ID 去重，关闭订阅时注销队列。
3. 工作流 SSE 使用现有认证客户端；历史流允许原生重连。运行流增加序号 ID，
   恢复时按序号过滤，保持已有事件名和终态行为。
4. 增加针对错误事件、游标恢复、失效游标、回放并发及工作流恢复的测试。
   运行受影响测试、lint 与类型检查，浏览器验证不使用真实凭据输出。

不修改身份认证策略、生产静态构建或无关会话。每一步可通过撤回对应代码和测试回滚。
相对于失效游标时静默丢弃，现选择完整回放并记录警告；此回退可能重复事件，
但不会伪装成成功恢复。

## 实施与验证

- 聊天连接仅在处理业务事件成功后记录游标；切换或取消选择会话时清除。
  携游标重连时保留活动流状态，避免跳过起始事件后丢失流状态。
  后端在注册实时队列后创建回放快照，去重快照与队列的重叠事件。
- 工作流运行流使用数据库序号分页恢复，终态帧仍在所有待回放事件之后发送；
  运行事件的 `data` 直接使用数据库中的 JSON，不再重复编码。
- 前端三组相关测试共 94 项通过，TypeScript 检查通过，lint 有既存警告。
  后端定向测试共 14 项通过，覆盖端点游标透传、失效游标后的实时事件、
  回放并发与去重、取消清理、协议不兼容、工作流分页和非法游标；
  相关代码 lint 排除既存问题后通过。
- 完整 Python 异步 SSE 测试在当前环境运行 30 秒后未完成，已停止；上述

## 后续验收

1. 在支持正常创建 Python 异步事件循环的环境中，从项目根目录运行完整的相关测试：

   ```powershell
   python -m pytest tests\test_sse_single_track.py tests\test_workflow_sse_stream.py tests\test_sse_heartbeat.py -q -p no:hypothesispytest -p no:hypothesis
   ```

   若再次卡住，可先单独运行 `python -c "import asyncio; asyncio.run(asyncio.sleep(0.01))"`；
   该命令也无法退出时，应先排查环境，不能把它当作 SSE 测试通过。

2. 由服务使用者确认当前没有需要保留的运行任务后，停止并重启现有后端，使 Python
   改动生效；前端开发模式和启动命令见 [前端 README](../../webui/frontend/README.md)。
   前端热更新不等于后端自动重载。
3. 使用测试会话验证：正常收发消息；受控触发业务错误时错误提示可见且健康连接
   不被误标为断开；制造一次临时网络中断后，确认连接恢复、游标继续传递，并且只
   回放游标之后的事件。若期间没有新事件，应无历史业务事件重放。
   观察工作流运行流和历史流的认证与重连，确认终态能够正常显示。
4. 日志里的 `total_events` 包含心跳，不能直接当作重放业务事件数。失效游标的预期
   是警告加完整回放；这与有效游标增量恢复不是同一种情况。

分享测试结果时请删除认证令牌、Cookie、会话标识和完整请求 URL；浏览器网络面板中的
SSE URL 可能包含认证参数。若测试失败，保留脱敏的事件类型、数量和时间间隔以便定位。
