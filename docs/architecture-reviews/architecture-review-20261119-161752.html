Problem. 生产 container、dependency fallback、router cache 分别持有部分身份与生命周期规则；router cache 缺少明确 close。

Solution. 按已落库 M12 方案集中资源所有权与 close 规则，保留真实存在的测试、脚本入口，不盲删 fallback。

Wins. locality：构造与 close 可一处核验；leverage：多个入口复用资源图；identity 与释放行为可定向测试。

审批状态。 尚待四项裁决：方案形态；本轮是否做子批 1–4；router cache 的 close 时机；app lifespan 是否显式 close。推荐接受方案形态和 1–4、子批 5 延后；cache reset 与进程退出都覆盖，并为重复 close 建测试；lifespan 同批补齐。
