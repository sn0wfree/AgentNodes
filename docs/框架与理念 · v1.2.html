一句话

物理轴（L1–L4）管「谁可以 import 谁」，语义轴（G/E/P）管「谁可以改变谁」；
两轴在 Tier 0/1/2 相交；三条反馈回路按分钟 / 小时 / 天分时标运行；
评估器与变异白名单的守护在进程外。

v1.2 追加：执行面已收敛为单引擎（LoopEngine）， 结构门禁从「手动跑」变为 pytest + CI 双闸， kernel/ 业务名词归零已由自动化守住。

七条理念 · 张力 + 规则 + 检查（检查栏已回填 v1.2 实测）

理念 01
双轴正交：物理轴管依赖，语义轴管变异
张力GEP-RSI 的全部缺口在 import 图上恒为 0——物理门禁全绿 ≠ 架构对
规则两轴不互相推导也不合并；桥接点是 Tier 0/1/2
检查8 道结构门禁齐备（scripts/arch 14 文件），已接 pytest（26→28 用例）+ CI（architecture-gates job）。语义轴 Tier 0 三重冻结在 proposals/validation_gate/skill_memory ✅
理念 02
变更三关口：提案 → 验证 → 留痕
张力能直接改配置的 agent 总能把指标调好看
规则GenomeProposal 唯一入口（构造期拒 Tier 0）→ ValidationGate 唯一生效入口 → 事件 + 版本链 append-only
检查三道已成立 ✅。残差：set_tier2 生产调用 0 处（Tier 2 设计了没接线，D6 拍了板未落地）
理念 03
注册即可运行，或不可见
张力业务工具注册成功、调用必败（CapabilityNotFound）——端口化把失败从编译期推到运行期
规则kind 注册的前提 = 全部依赖 kind 可解析；不满足 → 整组不注册 + WARN，绝不注册必然失败的壳
检查✅ 已落地：requires 声明 95 处；apps/capabilities.py 注册带 requires；check_capability_requires consistent
理念 04
评估器在循环外，终止层级在进程外
张力评估器可被循环改写 = 自进化退化为自欺骗；「永远不可变」又不可实现
规则评估器不在 Tier 1 白名单（闭合集合）；修改唯一路径 = PR + 人审 + 包外门禁；终止层级 = scripts/arch + 测试 + 人
检查评估完整性指纹已落地（evals/golden_sets 相关 114 处）；终止层级 = 8 道门禁 + 28 条 pytest 断言 + CI job ✅
理念 05
两条反馈回路不合并，goal 是桥
张力合并会把两种噪声混在一起，并让「把判据写松」成为指标攻击面
规则能力反馈（golden eval，冻结基准）喂第 5 步双门；任务反馈（goal journal）喂第 1 步诊断；端口方向恒为 L2 → L3
检查⚠️ 端口未接：JournalSource/ScoreboardSource 协议已声明，但 apps/goal/journal_source.py 与 scoreboard_source.py 不存在；interfaces/rsi_wiring.py:219 四源仍同指 EventStoreReportSource。R3 未做
理念 06
没有驱动的循环不存在
张力五个零件各有测试，build_rsi_loop() 生产零调用——七步之外缺第 0 步：谁拉起一轮
规则主驱动 run.settled 收尾钩子 + cron 兜底 + 每 session 至多 1 cycle（复用容量闸）；阶段 2 前置 = 判据强度门 + 事件写入方鉴别
检查⚠️ 部分：build_rsi_loop 12 处引用、rsi.cycle_started/cycle_skipped 12 处已有；cron 兜底 0 处（阶段 1 只落了一半）
理念 07 · v1.1 新增
检查信号必须经由被检方不可控的通道产生
张力全部「检查」的通过信号都由被检查方自己产出——自报 requires / 自报事件 / 自写 evidence（实测 evaluate("true")==True）/ 同进程可投毒的 golden eval。不是四个 bug，是缺一条原则
规则检查信号通道三选一：kernel 侧计算 / 进程外持有（held-out 由包外脚本持有）/ 不可伪造源（append-only + 未来 hash chain）
检查held-out 包外持有 ✅（469 处）；append-only 10 处 ✅；hash chain 0 处（D5 拍板延到 P2）。残差诚实声明：evaluate("true")==True 的恒真判据形态仍是已知攻击面（interfaces/goal_settled_consumer.py:18,34 有注释记录）
